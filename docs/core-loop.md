# Core Loop 정의 (1회 플레이)

## 1) 1회 플레이 루프

한 번의 기본 진행 단위는 아래 순서를 따른다.

1. **전투 시작**
   - 맵에서 전투 노드(일반/엘리트/보스) 진입 시 적 조합을 생성한다.
   - 플레이어 덱을 셔플하고, 시작 손패/에너지/상태이상 지속값을 초기화한다.
2. **턴 진행**
   - 플레이어 턴과 적 턴이 번갈아 진행된다.
   - 플레이어는 에너지를 사용해 카드를 사용하고, 턴 종료 시 손패를 정리한다.
   - 적은 의도(Intent)에 따라 스킬/공격을 실행한다.
3. **승/패 판정**
   - 적 전멸 시 승리.
   - 플레이어 HP가 0 이하가 되면 패배(런 종료).
4. **보상 선택**
   - 승리 시 골드/카드/유물(또는 소비 아이템) 후보를 제시한다.
   - 플레이어는 제한된 선택지 중 하나 이상을 선택하거나 스킵한다.
5. **맵 이동**
   - 현재 노드와 연결된 다음 노드 중 하나를 선택한다.
   - 보스 처치 전까지 위 루프를 반복한다.

---

## 2) 전투 규칙 (수치 포함)

### 2.1 기본 수치

- **플레이어 시작 HP**: 80
- **전투 시작 에너지**: 3
- **턴 시작 드로우**: 5장
- **턴 종료 손패 처리**: 기본적으로 전량 버리기(지속 카드 제외)
- **최대 손패**: 10장
- **덱 소진 시**: 버린 더미를 셔플해 새 드로우 더미 생성

### 2.2 턴 순서(정확한 적용 순서)

#### 플레이어 턴 시작
1. `턴 시작 트리거` 발동(턴 시작 시 효과, 디버프 감소 등).
2. 에너지를 기본값(3)으로 리필.
3. 카드 5장 드로우(최대 손패 초과분은 즉시 버림).
4. 자동 적용 상태이상 처리:
   - **독(Poison)**: 턴 시작에 피해 적용, 이후 수치 1 감소.
   - **취약(Vulnerable)**: 받는 공격 피해 +50%, 턴 종료 시 1 감소.
   - **약화(Weak)**: 주는 공격 피해 -25%, 턴 종료 시 1 감소.
   - **화상(Burn)**: 손패에 있으면 턴 종료 시 카드 1장당 2 피해.

#### 플레이어 행동 단계
- 카드 사용 시 비용만큼 에너지 차감.
- 에너지 부족 시 해당 카드 사용 불가.
- 카드 해소 순서: `비용 지불 → 대상 지정 → 피해/방어/상태이상 적용 → 카드 이동(버림/소멸)`.

#### 플레이어 턴 종료
1. 손패 버리기(지속/고정 키워드 카드는 유지 가능).
2. 턴 종료 트리거 처리.
3. 지속시간 기반 버프/디버프 감소(명시된 효과 우선).

#### 적 턴
1. 살아있는 적을 속도 순(동률 시 좌→우)으로 처리.
2. 각 적이 의도(Intent)에 따라 행동 실행.
3. 적의 지속효과/쿨다운 갱신.
4. 모든 적 행동 종료 후 다음 플레이어 턴으로 전환.

### 2.3 피해 및 방어 계산

- 기본 공격 피해 공식:
  - `최종 피해 = floor(기본 피해 × 공격측 증감 배율 × 방어측 증감 배율) - 방어도`
  - 최소 피해는 0.
- **방어도(Block)**는 같은 전투 턴 종료 시 기본 0으로 초기화.
- **저항(Resist)**은 별도 계수로 적용:
  - 속성 피해일 때 `속성 피해 × (1 - 저항률)`.
  - 예: 화염 저항 30%면 화염 피해 10 → 7.

## 3) 맵 노드 타입 및 출현 규칙

## 3.1 노드 타입

- **일반전투 (Normal)**: 기본 보상 수급 구간.
- **엘리트 (Elite)**: 고난도 전투, 강화 보상(유물 확률 상승).
- **휴식 (Rest)**: 회복 또는 덱 강화(카드 업그레이드).
- **상점 (Shop)**: 골드로 카드/유물/소모품 구매.
- **이벤트 (Event)**: 선택지 기반 리스크/리워드.
- **보스 (Boss)**: Act 마지막 전투, 다음 단계 해금 조건.

## 3.2 출현 규칙 (Act 1 기준)

- Act 1 노드 수: **총 15개 층 + 보스 1개 고정**.
- 시작점에서 매 층 2~3개 경로 분기.
- 초반 1~3층에는 **엘리트/보스 미출현**.
- 일반 층(보스 제외)의 목표 분포:
  - 일반전투: **45%**
  - 이벤트: **20%**
  - 휴식: **15%**
  - 상점: **10%**
  - 엘리트: **10%**
- 제한 규칙:
  - 휴식은 연속 2회 이상 배치 금지.
  - 상점은 최소 4층 간격.
  - 엘리트는 경로당 최대 3개.
  - 보스 직전 층은 휴식 또는 이벤트 중 하나를 강제 배치.

## 4) DCSS 요소 매핑 및 우선 도입 항목

Slay the Spire식 진행에 DCSS 감성을 얹되, MVP 기준으로 아래 순서로 도입한다.

### 4.1 도입 후보

- **종족(Race/Species)**: 시작 스탯, 고유 패시브 차별화.
- **신앙(God/Faith)**: 특정 행동 선호/금기와 보상 능력.
- **룬(Rune)**: 장기 목표형 메타 진행(특수 보스 격파 증표).
- **저항(Resistance)**: 화염/냉기/전기/독 등 속성 방어.

### 4.2 우선순위 (MVP)

1. **저항 시스템** (1순위)
   - 전투 수치에 바로 반영 가능하고 카드/적 설계 확장성이 높음.
2. **종족 시스템** (2순위)
   - 시작 덱/시작 유물/기초 능력치 차별화로 리플레이성 확보.
3. **신앙 시스템** (3순위, 축소형)
   - 완전한 금기 시스템 대신 “신앙 패시브 1개 + 발동 액티브 1개”만 도입.
4. **룬 시스템** (MVP 제외, Post-MVP)
   - 메타 진행 설계 비용이 커서 후속 업데이트로 이관.

---

## 5) MVP 범위 (2~3주 고정)

아래 범위를 **MVP 고정 스코프**로 확정한다.

### 5.1 반드시 포함

- 1개 Act(15층 + 보스)
- 플레이어블 종족 2종
- 기본 카드 60장 내외(공용 + 종족 전용 일부)
- 적 12종(일반 8, 엘리트 3, 보스 1)
- 상태이상 4종(독/취약/약화/화상)
- 저항 4속성(화염/냉기/전기/독)
- 노드 6타입(일반전투/엘리트/휴식/상점/이벤트/보스)
- 전투 보상: 골드 + 카드 선택 + 저확률 유물

### 5.2 제외(고정)

- 신앙 심화 시스템(금기, 진노, 헌납 등)
- 룬 메타 진행
- 2개 이상 Act
- 멀티클래스/복합 종족
- 장비 내구도/식량/복잡한 시야 시스템

### 5.3 완료 조건(Definition of Done)

- 시작부터 보스 클리어까지 단일 런이 끊김 없이 진행된다.
- 핵심 수치(에너지/드로우/버리기/상태이상/저항)가 전투 로그로 검증 가능하다.
- 노드 생성 규칙이 실행 시드 기준으로 재현 가능하다.
- 평균 30~45분 내 1런 완료가 가능하다.
