# 다음 개발 계획 (단기)

요청하신 "한 번 실행해보기" 이후, 바로 이어서 진행할 수 있는 단기 계획입니다.

## 1) 전투 규칙 정확도 보강
- 턴 종료 시 `취약/약화` 감소 타이밍을 플레이어/적 각각 분리
- `화상(Burn)` 카드 기반 처리(손패 내 개수 반영)로 확장
- 의도(Intent) 시스템을 명시적 상태로 분리(다음 턴 예고)

## 2) 카드/덱 시스템 실제화
- 드로우 더미 / 버림 더미 / 소멸 더미 분리
- 턴 시작 5드로우, 덱 소진 시 셔플 재생성
- 카드 비용/타입(공격/스킬/파워) 데이터화

## 3) 맵 루프 연결 (전투 밖 루프)
- 전투 승리 후 보상 선택(카드/골드/유물) 프로토타입
- 노드 이동 규칙(연결 노드 중 선택) 최소 구현
- 시드 기반 경로 재현성 검증

## 4) 검증 자동화 강화
- 상태이상/저항 계산 표 기반 파라미터 테스트 추가
- 시드별 평균 턴 수/승률 스모크 리포트 스크립트 추가
- CI에서 `pytest` 자동 실행
